📖 Help

Basic Usage

  • Load Files: NES, CHR, ZIP, BIN file formats supported
  • Select Tile: Click on grid (left panel) to select 8x8 tile
  • Edit Pixels: Click on editor (right panel) to draw
  • Choose Color: Click color buttons or press 0-3 keys

⌨️ Keyboard Shortcuts

  • Ctrl+Z: Undo
  • Ctrl+Shift+Z: Redo
  • Ctrl+C: Copy tile
  • Ctrl+V: Paste tile
  • 0-3: Select color palette

💾 File Formats

  • CHR: NES character ROM (standard 8KB)
  • NES: NES ROM file (CHR auto-extracted)
  • BIN: Binary file
  • PNG: Export as image

🎨 Color Palette

  • 0 (Black): Background / transparent
  • 1 (Dark Gray): Shadow / outline
  • 2 (Light Gray): Midtone / highlight
  • 3 (White): Brightest highlight

🛠️ Tools

  • Flip H: Flip tile horizontally
  • Flip V: Flip tile vertically
  • Rotate: Rotate tile 90° clockwise
  • Copy/Paste: Tile copy & paste

💡 Tips

  • Tiles expand from initial 256 to maximum 1024
  • Use toolbar "+ Add 256 Tiles" to expand in blocks
  • Undo history supports up to 50 steps
  • Multiple export formats available
  • Metatile preview helps with tile arrangement
