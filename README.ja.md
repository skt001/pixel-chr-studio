# 🎨 Pixel CHR Studio

8x8 ピクセルのタイルと 16x16 メタタイルを編集できる、Web ベースの NES Character ROM (CHR) エディターです。

[English README](README.md)

## 機能

- **NES キャラクターデータの編集** — NES ゲームの CHR ROM ファイルを読み込んで編集
- **タイル数の拡張** — 必要に応じて 256 タイルから最大 1024 タイルまで拡張
- **複数の入力形式** — NES、CHR、BIN、ZIP ファイルに対応
- **タイル編集ツール** — 水平・垂直反転、90 度回転、コピー／貼り付け
- **リアルタイムプレビュー** — 編集中の 16x16 メタタイルをプレビュー
- **元に戻す／やり直し** — 最大 50 ステップの操作履歴
- **複数の出力形式** — CHR、BIN、PNG、16 進ダンプ
- **レスポンシブデザイン** — デスクトップとタブレットに対応
- **日英対応 UI** — 日本語版（`index.html`）と英語版（`index-en.html`）

## はじめ方

### 起動方法

HTML ファイルを最新の Web ブラウザーで開いてください。

```bash
# 日本語版
open index.html

# 英語版
open index-en.html
```

### 使い方

1. **ファイルを読み込む**
   - ファイル選択から NES、CHR、BIN、または ZIP ファイルを選びます。
   - ファイル形式は自動判別され、必要に応じてタイル数が拡張されます。
2. **タイルを選択する**
   - 左側のグリッドで 8x8 タイルを選択します。
   - 選択したタイルは右側のパネルに拡大表示されます。
3. **ピクセルを編集する**
   - エディター上のタイルをクリックして、選択中の色で描画します。
   - `0`〜`3` キーで色をすばやく切り替えられます。
4. **タイルを変形する**
   - **Flip H** — 水平方向に反転
   - **Flip V** — 垂直方向に反転
   - **Rotate** — 時計回りに 90 度回転
   - **Copy/Paste** — タイルをコピー／貼り付け
5. **書き出す**
   - 出力形式（CHR、BIN、PNG、または Hex）を選択します。
   - **Export** をクリックしてファイルをダウンロードします。

## キーボードショートカット

| キー | 操作 |
|---|---|
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Shift+Z` | やり直し |
| `Ctrl+C` | タイルをコピー |
| `Ctrl+V` | タイルを貼り付け |
| `0`〜`3` | パレットの色を選択 |

## 対応ファイル形式

- **NES** — NES ROM ファイル（CHR データを自動抽出）
- **CHR** — NES Character ROM（標準 8 KB）
- **BIN** — バイナリファイル（最大 16 KB）
- **ZIP** — NES、CHR、または BIN ファイルを含むアーカイブ

## カラーパレット

NES 標準の 4 色パレットを使用します。

- **0（黒）** — 背景／透明
- **1（濃いグレー）** — 影／輪郭
- **2（薄いグレー）** — 中間色／ハイライト
- **3（白）** — 最も明るいハイライト

## 技術情報

### タイルデータ

- 1 タイルは 16 バイト（2 ビットプレーン × 8 バイト）
- 256 タイル = 4 KB（最小サイズ）
- 512 タイル = 8 KB（NES 標準サイズ）
- 1024 タイル = 16 KB（最大サイズ）

### データ形式

NES CHR データは 2 ビットプレーン形式です。

- Plane 1（下位ビット）— バイト 0〜7
- Plane 2（上位ビット）— バイト 8〜15

### ブラウザー要件

- Chrome / Chromium 60 以降
- Firefox 55 以降
- Safari 11 以降
- Edge 79 以降

## ヒント

- タイルは 256 個単位（4 KB 単位）で拡張されます。
- ツールバーの **+ Add 256 Tiles** で追加できます。
- 元に戻す履歴は保存データとは別に管理されます。
- メタタイルプレビューでタイルの配置を確認できます。
- PNG 書き出しは作品の共有やドキュメント作成に便利です。

## 制限事項

- 最大 1024 タイル（16 KB）
- パレットは NES 標準の 4 色のみ
- Web アプリのため、オフライン保存機能はありません
- Canvas に対応した最新のブラウザーが必要です
